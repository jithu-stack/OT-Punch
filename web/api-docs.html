Connect Claude — OT Punch MCP

A read-only MCP server so Claude can answer questions from OT Punch: "Who needs attention today?", "Who hasn't reported in Team 3?", "October OT and TA per person". The OT maths stays in the database; Claude only reads the results.

day_boardEveryone's times, OT, TA, presence and status for a day, plus who hasn't reported
needs_attentionFlagged, not-yet-approved technicians for a day
monthly_reportHR list for a month: OT h, TA ₹, food days (approved only)
employee_historyOne technician, day by day, between two dates

One-time setup (admin)

  1. OT Desk → Setup → Staff logins: add mcp@stemhub.in with role hr. Then sign out and choose Create account with that email and a strong password.
  2. Vercel → ot-punch → Settings → Environment Variables: add MCP_TOKEN (a long random string), MCP_EMAIL and MCP_PASSWORD. Then Deployments → Redeploy.
  3. OT Desk → Setup → Connect Claude (MCP): paste the token and Copy MCP link.
  4. Claude → Settings → Connectors → Add custom connector → paste the link. In Claude Code: claude mcp add --transport http ot-punch "<link>"

Anyone with the link can read OT data. Share it only inside the team, and change MCP_TOKEN in Vercel to revoke it.
